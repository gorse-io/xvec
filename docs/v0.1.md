# v0.1 capability matrix

v0.1 is the first independently usable native Go milestone. Its behavioral
baseline is zvec commit `58375ff`, while its disk files are deliberately new
and begin at `NativeDiskFormatVersion == 1`.

## Supported

| Area | v0.1 behavior |
| --- | --- |
| Runtime | Pure Go, no CGO; Linux, macOS, and Windows builds |
| Lifecycle | Create/open, writable and read-only handles, Close, guarded Destroy, in-memory Stats/Schema/Options |
| Durability | Checksummed WAL, incomplete-tail recovery, atomic manifests, Flush/segment rotation, reopen without Flush |
| Writes | Ordered per-document results for Insert, partial Upsert/Update, Delete; mixed batches preserve successful writes |
| Fetch | Ordered results, nil for missing keys, scalar/vector projection |
| Dense search | Exact unquantized Flat over VECTOR_FP16, VECTOR_FP32, and VECTOR_INT8; L2, IP, cosine distance, and MIPS-L2 |
| Sparse search | Exact unquantized Flat over SPARSE_VECTOR_FP16/FP32 with inner product |
| Query controls | Positive top-k, inclusive metric-aware radius, deterministic document-ID ties, projections |
| Group-by | Supported scalar group types, per-group top-k, deterministic group ranking, baseline string formatting |
| Native files | Versioned/checksummed manifest, CURRENT, WAL, segment, primary-key/delete snapshot, schema, and document codecs |

## Explicitly unavailable

The following APIs return `ErrNotSupported`; v0.1 does not silently fall back
to a different algorithm:

- SQL filters and `DeleteByFilter`;
- scalar inverted indexes, DDL, Optimize, and deletion reclamation;
- HNSW, HNSW-RaBitQ, IVF, Vamana, DiskANN, and all quantized Flat execution;
- FTS, MultiQuery, RRF, weighted fusion, and callback reranking;
- reading or importing the C++ collection format.

`EnableMmap` is persisted for the later segment/index readers, but v0.1 verifies
immutable segment bytes into Go-owned memory. `MaxBufferSize` is likewise
reserved for later disk-index caches. These settings do not change v0.1 exact
query results.

## Verification gates

The release gate runs `go test ./...`, `go vet ./...`, `go test -race ./...`,
the manifest/WAL/document/schema fuzz seeds plus active schema fuzzing, and
no-CGO compilation for Windows and macOS. Storage tests cover incomplete WAL
tails, checksum corruption, unpublished artifacts, process-exit recovery,
atomic flush failure, and reopen consistency.
